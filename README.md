В рамках лабораторной работы на страницу был добавлен файл script.js и подключён в index.html перед закрывающим тегом </body>. Скрипт реализует следующую логику:
Ввод/вывод и работа с пользователем:
С помощью prompt запрашивается имя пользователя.
С помощью alert выводится персонализированное приветствие.
Введённое имя и ход выполнения программы логируются в консоль через console.log.
Исходные данные:
Создан массив gameHours из 7 чисел: [12, 2, 8, 15, 3, 1, 6]. Каждое число — это время (в часах), проведённое в разных играх за неделю.
Написаны три функции:
findMax(arr) — функция для поиска максимального значения в массиве (самая долгая игровая сессия).
filterGames(arr, threshold) — функция фильтрации, которая возвращает новый массив с играми, где время > 10 часов.
sumArray(arr) — функция для подсчёта суммы всех чисел в массиве (общее время).
Логика с использованием циклов и условий:
С помощью цикла for подсчитано количество «лёгких» игр (время ≤ 3 часов).
Вычислена доля (в процентах) коротких игровых сессий от общего количества игр.
С помощью условий if реализована проверка: если общая сумма времени > 25 часов, в консоль выводится предупреждение: «Возможно, стоит сбалансировать время между играми и учёбой».
Вывод результатов (строго по заданию):
Через alert выведено сообщение: «Вы провели X часов в играх, из них Y часов – в самых популярных» (где X — общая сумма часов, Y — сумма часов в играх, где время > 10).
Через console.log выведено:
Максимальное время в одной игре.
Отфильтрованный массив популярных игр (> 10 часов).
Количество «лёгких» игр (≤ 3 часов).
Доля коротких игровых сессий в процентах.
Предупреждение о балансе времени (если сумма > 25).
